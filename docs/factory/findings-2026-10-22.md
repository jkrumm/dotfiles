**Aligned setup (text elements, verbatim in substance):** mother → lead → wave is the
fleet flow; *sessions* are plain agents outside it. Warden receives issues by webhook
or by pulling HyperDX/Slack, writes them as Beads, and the mother triages them. Warden
and Beads share triage progress; an Artifact can hold the plan for many waves whose
tasks then live in Beads. Hermes talks to mothers or spawns individual sessions (brain,
investigation, planning). The mother coordinates across Beads and stays lean; the lead
coordinates the implementing waves, issue resolution and rebases; waves implement,
review, test, deploy, verify and ship. Mother and lead run Opus at medium effort; the
lead picks the wave model by complexity and quota (Opus for hard, Sonnet for easy,
OpenCode when Claude quota is low; modelpick suggests). Haiku for exploration.
agent-, research- and image-gateway are supporting CLIs. Also on the canvas: Herdr
GPUI, Slack.

**Argo project page (wireframe):** project name; links (herdr mother, app, git, …);
key stats; needs attention; tasks; todos; artifacts; health; changelog; cost stats;
traffic; git status; dependency state.

**Artifact review (MacBook, 2026-10-21):** PullMark rejected (Markdown only, macOS
app, no API, SMB). plannotator is the best ready-made tool for *blocking* plan review

## Prior art, verified 2026-10-21/22

Full reports with citations: `research/`. The facts that change decisions:

- **beads** v1.3.1 (2026-09-30, MIT) now runs on **Dolt** (embedded single-writer by
  default; server mode for many writers; one shared server holds one DB per project
  prefix); JSONL is an export only. `bd ready` is the blocker-aware queue. Claim leases,
  heartbeat and reclaim, compare-and-set (`--if-status`, exit 13), and `bd serve` (HTTP,
  41 operations) since v1.3.0. Cross-repo `external:` deps; `bd init --contributor`
  routes issues to a separate planning repo (an IuRoot fit). Weakness: backend and
  schema churn (v1.2.1 shipped by accident and migrated databases).
- **Gas Town** (MIT, v1.2.1 of 2026-06-06, main still moving; a successor "Gas City" is
  unverified): Mayor; Polecats (persistent identity, ephemeral sessions); the *hook* —
  a git worktree that owns the work, so a respawned session resumes; Witness (stuck
  detection), Deacon (patrols), Refinery (bisecting merge queue); `gt feed --problems`.
  Weakness: cost (third-party estimate ≈ 10× tokens) and convergence.
- **StrongDM software factory:** holdout scenarios stored outside agent-visible scope,
  scored on observed behaviour; a Digital Twin Universe of third-party services; CXDB
  plus a "Healer" that clusters bad behaviour into diagnoses and spawns investigators.
  No published delivery metrics.
- **Shapiro's five levels** (2026-01-23): the bottleneck moves typing → review →
  spec and verification; Level 5 has no acceptance criteria.
- **Durable execution on one mini:** Absurd 0.5.1 (Postgres, one SQL file, Apache-2.0,
  experimental); DBOS 5.3.0 (Postgres library, MIT); Restate 1.8.1 (single binary,
  server BUSL-1.1); Mastra 1.79 (library, libSQL adapters); XState 5.33 (no
  persistence). Temporal and Trigger.dev are heavy. None is SQLite-native.
- **MCP vs CLI:** Anthropic's numbers say tool-definition bloat is the cost (150k → 2k
  tokens with code execution; ≈ 77k → 8.7k with tool search). Independent CLI-vs-MCP
  benchmarks could not be verified, so measure on our own gateways.
- **Claude Code OTel:** metrics and events are documented; traces are beta
  (`CLAUDE_CODE_ENHANCED_TELEMETRY_BETA=1`); `TRACEPARENT` propagates into Bash
  subprocesses and MCP HTTP calls, so a herdr worker can join a warden-rooted trace.
- **Incident tooling:** Keep v0.54.3 (MIT core plus `ee/`; partial and full dedup;
  correlation rules; an incident-candidate gate; HyperDX only via webhook); Sentry is
  FSL (not OSS), GlitchTip MIT; Grafana OnCall OSS archived 2026-03-24, so the pager
  path is self-built either way; HolmesGPT 0.45 (Apache-2.0, no-Kubernetes mode, HTTP
  API, Docker and ClickHouse toolsets); Coroot's RCA is Enterprise-only; CrowdSec 1.8.1
  (MIT, crowdsourced blocklist); Netdata GPL-3.0; Renovate (AGPL; automerge minor/patch
  of non-0.x deps behind CI; `minimumReleaseAge` 14 days).
- **Evaluation:** score grouping with B-cubed and entity-centric sampling (n ≥ 400);
  pairwise F1 on a hand-labelled sample is optimistic and reverses rankings. Kubernetes'
  level-triggered controller pattern as the reconcile template. DORA is now five
  metrics (adds failed-deployment recovery time and deployment rework rate); `fourkeys`
  is archived. Pumba (containers) and Toxiproxy (TCP) for fault injection.
- **Review and cockpit tools:** plannotator 0.28.25; `petergyang/human-review` v0.8.2
  (MIT, MD and HTML comments sent back to the agent; workflow unverified); Claude Squad
  (AGPL); Crystal deprecated. Round 5's landscape (Blume deliveries, Conductor, Vibe
  Kanban, Omnara, Sculptor) is in `research/2026-10-21-dark-factory-landscape.md`.

Not covered by research yet: known-error-database and regression-detection practice;
Robusta, Falco, Wazuh, docker-autoheal; Netdata's ML anomaly detection; Temporal's
human-in-the-loop docs.
